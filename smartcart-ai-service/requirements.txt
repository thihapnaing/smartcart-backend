# Fixes "SSL: CERTIFICATE_VERIFY_FAILED - unable to get local issuer
# certificate" when calling api.openai.com. Cause: security software (e.g.
# Norton) doing HTTPS inspection injects a locally-trusted root CA that
# Windows trusts but Python's bundled certifi bundle does not. This patches
# Python's ssl module at import time to use the OS (Windows) certificate
# store instead of certifi, so anything Windows already trusts, Python does
# too. Just needs to be installed - no code changes required to use it.
